# Безопасность

Проект управляет нагревателем. Ошибки в логике регулятора и аварийного отключения считаем уязвимостями.

## Сообщить о проблеме

Используйте Private vulnerability reporting: вкладка Security → Report a vulnerability.
Не публикуйте детали в открытых issue до исправления.

## Секреты

Не коммитьте пароли Wi-Fi, токены и ключи. Если секрет попал в историю, считайте его скомпрометированным и замените.
