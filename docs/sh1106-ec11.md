# SH1106 I2C + EC11 + CON/BACK

Окружения: `esp32s3-sh1106-ec11`, `pico2-sh1106-ec11`, `pico2w-sh1106-ec11`.
Это отдельные профили модуля с фото; для Waveshare RP2350-LCD-0.96 они не предназначены.

| Модуль | ESP32-S3 GPIO | Pico 2 / 2 W GP |
|---|---|---|
| 3V3 / GND | 3V3 / GND | 3V3(OUT) / GND |
| SDA / SCL | 8 / 9 | 4 / 5 |
| TRA / TRB | 6 / 7 | 6 / 7 |
| PSH | 15 | 8 |
| CON | 17 | 10 |
| BAK | 18 | 11 |

CON повторяет короткое/длинное нажатие PSH. BACK срабатывает один раз после 30 мс устойчивого нажатия: из Edit/Sensors/Network в Menu, из Menu в Main, на Main ничего не делает. BACK не сохраняет редактируемое значение и не вызывает start/stop/ack.
Все кнопки — INPUT_PULLUP, замыкание на GND. Новые пины задаются PIN_BTN_OK/PIN_BTN_BACK, по умолчанию -1. Питание модуля только 3.3 В. При обратном вращении используйте ENC_REVERSE.

После загрузки требуется отпустить кнопки на 30 мс. Одновременные нажатия и переход с одной кнопки на другую без устойчивого отпускания отменяют жест до отпускания всех кнопок. Это относится и к старым окружениям с одним PSH: удержание при загрузке больше не считается командой запуска.

## Проверка

```sh
pio test -e native
pio run -e esp32s3-sh1106-ec11 -e pico2-sh1106-ec11 -e pico2w-sh1106-ec11
pio run -e esp32s3-oled -e pico2-oled -e pico2w-tft
```

`test/test_input` проверяет клик, удержание, отсутствие повторов, дребезг, зажатую кнопку при загрузке, комбинации/частичное отпускание, переполнение времени и навигацию BACK. Основной CI запускает native-тесты и прежние окружения; дополнительный workflow SH1106 EC11 собирает три новых профиля и выводит размер прошивки. Полную сборку и аппаратную проверку нужно выполнить до слияния.

Проверка без парафина, с лампой вместо ТЭНа: загрузка с зажатой CON/PSH не включает выход; после отпускания короткий CON открывает меню; BACK отменяет Edit и не включает нагрев в IDLE/FAULT. Удержание CON 1.2 с запускает только явно запрошенный нагрев. Комбинация CON+BACK и частичное отпускание не запускают нагрев. Отключение датчика гасит лампу, сброс аварии при неисправном датчике отклоняется. После перезапуска и сброса аварии выход остаётся выключенным до новой команды пользователя.

Контур управления, Safety, SSR и AppSettings не изменены. Основной риск правки — ложные события ввода; до работы с ТЭНом проверить все перечисленные сценарии.

Последовательно с ТЭНом обязателен NC-термовыключатель KSD301/KSD9700; также автомат, заземление и подтяжка SSR-пина 10 кОм к GND. Парафин водой не тушить.
