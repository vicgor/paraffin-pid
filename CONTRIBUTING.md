# Участие в разработке

## Workflow

1. Одна задача: одна ветка от актуального `main` (`feature/...`, `fix/...`, `chore/...`).
2. Синхронизация только через rebase: `git fetch origin && git rebase origin/main`.
3. Откройте PR. В `main` напрямую пушить нельзя (ruleset).
4. Для слияния нужен зелёный check `CI OK`, актуальная ветка и закрытые обсуждения.
5. Способ слияния: squash.

## Проверки локально

```bash
pio test -e native
pio run -e esp32s3-sh1106-spi
```

## Требования

- Изменения управления нагревом проверяйте на стенде.
- Не коммитьте секреты (`.env`, пароли Wi-Fi).
